# AGENTS.md

## Local Dev

- `spotify-dev`: run `bun run dev`. The local dev server listens on port 5174.
- `local-music`: run `bun run local:music`. The local service listens on port 5176.
- `ios-sim`: from `mobile`, run `bun run ios -- --device C19AFA72-424A-441A-97F9-D31DB7E7C17E`. Use the Xcode selected by `xcode-select` (Xcode 27); this targets the iOS 27 iPhone 17 Pro simulator.
